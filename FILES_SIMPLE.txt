الخطوات السريعة:

1. أنشئ حساب على jsonbin.io (مجاني)
2. أنشئ Bin جديد بالبيانات:
   {
     "totalVisits": 0,
     "visits": []
   }
3. احصل على JSONBin ID و API Key
4. تحديث tracker-simple.js بالمعرفات
5. ارفع الملفات المذكورة أعلاه إلى GitHub
6. فعل GitHub Pages
7. افتح stats-simple.html وأدخل المعرفات
8. شاهد الإحصائيات!
