# موقع عملي برمجة 3

## 📚 المحتوى

- **lectures.html** - صفحة المحاضرات مع نظام التتبع البسيط
- **stats-simple.html** - صفحة عرض الإحصائيات

## 🎯 نظام التتبع البسيط

يستخدم JSONBin.io لتتبع:
- **عداد الزيارات الكلي**
- **قائمة بكل زيارة مع التاريخ والوقت**

## ⚡ الميزات

- ✅ لا يحتاج سيرفر
- ✅ لا يحتاج تسجيل دخول
- ✅ مجاني تماماً
- ✅ سهل الإعداد (5 دقائق)

## 🚀 خطوات الإعداد السريعة

### 1. إنشاء حساب JSONBin
اذهب إلى [jsonbin.io](https://jsonbin.io) وسجل حساباً مجانياً

### 2. إنشاء Bin جديد
أنشئ Bin جديد بالبيانات:
```json
{
  "totalVisits": 0,
  "visits": []
}
```

### 3. الحصول على المعرفات
- JSONBin ID من رابط Bin
- API Key من API Keys page

### 4. تحديث tracker-simple.js
استبدل `YOUR_JSONBIN_ID` و `YOUR_JSONBIN_API_KEY` بالمعرفات الخاصة بك

### 5. رفع الملفات إلى GitHub
ارفع الملفات المذكورة في `FILES_SIMPLE.txt`

### 6. تفعيل GitHub Pages
من Settings → Pages

### 7. عرض الإحصائيات
افتح `stats-simple.html` وأدخل المعرفات

## 📖 الوثائق

- `SETUP_SIMPLE.md` - دليل الإعداد الكامل
- `FILES_SIMPLE.txt` - قائمة الملفات المطلوبة

## 🔧 التقنيات المستخدمة

- **GitHub Pages** - استضافة الموقع
